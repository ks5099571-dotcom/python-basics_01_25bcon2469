# Fibonacci Series in Python

A simple Python program that generates the Fibonacci series up to a 
specified number of terms. This project demonstrates basic Python 
programming concepts such as variables, loops, user input, and arithmetic 
operations.

## 📌 Project Description

The Fibonacci series is a sequence in which each number is the sum of the 
two preceding numbers.

The series starts with:

`0, 1, 1, 2, 3, 5, 8, 13, ...`

For example:

`0 + 1 = 1`  
`1 + 1 = 2`  
`1 + 2 = 3`  
`2 + 3 = 5`

This project is suitable for beginners learning the fundamentals of 
Python programming.

## ✨ Features

- Generates the Fibonacci series.
- Accepts the number of terms from the user.
- Uses a simple loop-based approach.
- Easy to understand and execute.
- Demonstrates basic Python programming concepts.

## 🛠️ Requirements

- Python 3.x
- Any Python-compatible IDE or code editor
- Command Prompt / Terminal (optional)

No external libraries are required.
