 Fibonacci Series Program

A simple beginner Python program that generates the Fibonacci series using a loop.

Program

The repository contains:

fibonacci series.py — generates the Fibonacci series.
How It Works

The Fibonacci series starts with 0 and 1.

A for loop generates the next numbers in the series by adding the previous two numbers.

For example:

0, 1, 1, 2, 3, 5, 8

Requirements
Python 3.x

No external libraries are required.

Usage

Run:

python "fibonacci series.py"
Output
0 1 1 2 3 5 8
Example Calculation
0 + 1 = 1
1 + 1 = 2
1 + 2 = 3
2 + 3 = 5
3 + 5 = 8
